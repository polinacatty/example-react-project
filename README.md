# Example React Project

Учебный проект на React — мини-сайт с возможностью просмотра, добавления объявлений и комментариев к ним, а также авторизацией.

## 🛠 Технологии

- **React**
- **React Router DOM**
- **Redux** + **Redux Thunk**
- **Jest** + **React Testing Library**
- **CSS**

## 📋 Требования

- Node.js 18+
- npm 9+

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/polinacatty/example-react-project.git
cd example-react-project
```

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm start
```

### Запуск тестов

```bash
npm test
```
